# Store Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a public authenticated merchandise store and a fifth administrative Store section for products, variant stock, and manual-payment orders.

**Architecture:** Products and orders are separate bounded modules under the academy tenant. The browser manages local cart presentation only; Functions validate prices, stock, ownership, delivery, and order totals. No payment gateway, email provider, or external commerce platform is introduced.

**Tech Stack:** Next.js 16, React 19, Firebase Auth, Firebase Functions v2, Firestore, Cloudflare R2 via `@aws-sdk/client-s3` and `@aws-sdk/s3-request-presigner` for private product images, Zod, Vitest, React Testing Library, Playwright.

## Global Constraints

- Customers must authenticate before checkout.
- No online payment in this version.
- Orders are created server-side with prices and stock revalidated.
- Customers can read only their own orders; administrators can manage academy orders.
- Stock is tracked per product variant, including size and color.
- Delivery options are pickup or fixed-rate delivery.
- Order confirmation is an on-screen order number; no automatic email.
- No card data, payment secrets, or credentials are stored.
- Product images use controlled storage paths and validated content types.
