# T010 — Autorización del operador

**Fecha:** 2026-09-01  
**Decisión:** aceptar validar CityPay Limited + Paylink alojado para pagos únicos en GBP.

## Alcance autorizado

El operador autoriza solicitar onboarding, cotización, términos y acceso sandbox/test accounts.

## Exclusiones explícitas

Esta autorización no permite:

- contratar ni firmar términos;
- pagar setup, mensualidades u otros cargos;
- activar producción o procesar cobros reales;
- solicitar, copiar o almacenar credenciales de producción;
- introducir datos de tarjeta o datos reales de clientes;
- marcar T010 como aprobada.
